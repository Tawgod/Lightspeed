## Limits and drift
Shared structural validators reduce maintenance drift; transaction and remote lifecycles remain separate to avoid collapsing distinct semantics. M8 checks fresh derivation before final dispatch decision (M7 legacy ordering differs); M8 extra replay decision and rich scope commitment intentional. Neither profile provides distributed atomic revocation fence, production persistence, actual vendor causal proof or independent post-revocation reconciliation authority. Security policy revisions/assurance changes must be authoritative; same-clock synthetic check is not production lifetime. Production requires atomic admission/commit fencing or explicitly accepted residual window, durable dispatch fencing and independently authorized reconciliation, no blind retry. Core cannot guarantee atomic remote vendor effect with local authorization. No broad new access or migration approved.
