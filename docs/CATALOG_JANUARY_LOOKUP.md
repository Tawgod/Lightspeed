## Native typed product codes — additive revision

Legacy SKU stays SKU; 2026-10 migration maps SKU to CUSTOM without proving every CUSTOM is a SKU. Existing ALIAS, GTIN, supplier and manufacturer evidence remain distinct. All twelve namespace flags must be independently complete for untyped scan; old nine-flag snapshots now fail closed for untyped uniqueness/absence. Typed queries still require their own namespace coverage. TARGET/NAME unchanged. Multiple values per type are existing array semantics, no overwrite; exact canonical pair deduplicates same-target matches, distinct targets remain ambiguous.
Provider 2026-10 reads codes[] {type,code}; legacy reads product_codes[] and sku when present. Map only exact strings and recognized explicit types, preserve original provenance and member mapping; unknown or incomplete code lists block coverage. Do not infer type from length, normalize, or claim absent list is empty. ITF/JAN retained even if UI only edits four types. No actual provider adapter or writes here.
